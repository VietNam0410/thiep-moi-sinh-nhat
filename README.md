# Thiệp Mời Sinh Nhật — Việt Nam

Live: https://vietnam0410.github.io/thiep-moi-sinh-nhat/

## Cách chạy
Mở trang GitHub Pages. Hard refresh: Ctrl+Shift+R (hoặc Cmd+Shift+R).

## File chính
- `index.html` — HTML + CSS
- `horse.js` — sprite pixel ngựa
- `s0a.js` + `s0b.js` + `s0c.js` — logic (được load qua `appload.js`)
- `app.source.js` (local) — bản 1 file đầy đủ để chỉnh sửa

## Chỉnh nội dung
Trong `s0a.js` tìm `CONFIG` (thư, ngày, địa điểm, wishlist, gasEndpoint).

## Chèn nhạc
Trong `s0b.js` tìm `MUSIC #1` (mở thư).
Trong `s0c.js` tìm `MUSIC #2` (sau RSVP).
